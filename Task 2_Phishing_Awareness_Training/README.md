# Task 2: Phishing Awareness Training

## Project Overview
This project contains the training materials developed during the CodeAlpha Cyber Security Internship to educate users on recognizing and defending against phishing and social engineering attacks.

## Training Modules Covered
1. **Identifying Red Flags:** Analyzing sender email addresses, suspicious links, and urgent language.
2. **Social Engineering Tactics:** Understanding how attackers exploit human psychology (authority, fear, greed).
3. **Prevention Measures:** Best practices for multi-factor authentication (MFA) and secure reporting protocols.
